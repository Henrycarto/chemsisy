# Security

Chemsisy is a static web app with no accounts, no server and no user data. Problems can still happen: a script injection through content, a dependency with a known vulnerability, or a service worker caching something it should not.

## Report a problem privately

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe what you found, how to reproduce it and what it could affect.

Only the maintainer sees the report. You can expect a first reply within a week, and a fix or a plan within 30 days. You will be credited in the release notes if you want to be.

## Supported versions

Only the latest version on `main`, and the deployed site built from it, receive fixes.
